Projekt k maturnitní práci. Bez svolení autora nesdílet!

Hlavním cílem projektu je vytvořit 3D stealth hru zasazenou do prostředí sci-fi základny. Hráč se bude pohybovat interiérem, plnit úkoly a překonávat překážky, jako jsou patrolling nepřátele, bezpečnostní kamery a zamčené dveře, pomocí stealth mechaniky a bezpečnostních puzzlů. Selhání puzzlu spustí alarm a pokud je hráč chycen, mise okamžitě skončí.
